PRIVACY POLICY

隐私政策

适用应用：English Learning Bridge
更新日期：2026 年 11 月 26 日

本政策说明个人 Windows 英语学习归档工具 English Learning Bridge 如何处理学习资料和 Google 数据，也说明这个公开介绍网站的用途。本政策只覆盖此归档工具，不替代 Google、ChatGPT、GitHub 或其他来源服务各自的隐私政策。

处理哪些数据

  • 主动提供的学习内容：学习原文、用户练习、词汇复习数据、学习事件和报告。
  • 已授权的 Drive 文件：文件内容、版本及同步核验所需的文件元数据。
  • 授权账户信息：新授权验证时读取的 Drive 邮箱和账户权限标识，用于检查账户一致性。
  • 运行与诊断信息：同步阶段、错误码、事件标识、文件版本和内容哈希，用于查重、故障定位与恢复。

程序只归档实际取得并被提供的内容；不会因为使用此工具而自动取得全部 ChatGPT 对话。

为什么访问 Google Drive

程序请求 https://www.googleapis.com/auth/drive.file，用于在授权范围内读取和更新学习文件、保存学习报告，以及核对写入结果。Google 数据用于账号持有人选择的个人学习归档与恢复功能。

此工具没有广告投放、出售学习记录或向其他用户共享学习主库的功能。数据访问范围以 Google 实际授予的权限为准。

数据保存与凭据处理

原始学习记录、待传队列及诊断信息保存在本人的 Windows 电脑；归档文件和学习报告保存在本人的 Google Drive。工具没有为其他用户提供集中保存学习资料的服务器。

Google 刷新凭据使用 Windows 当前用户的 DPAPI 加密保存在本地私有存储中。访问凭据用于进程中的 API 请求，不写入学习记录。诊断日志不记录授权码、访问凭据、刷新凭据或客户端密钥明文。

这些是工具采用的数据处理措施，不构成独立安全审计或安全认证声明。

数据保留与删除

历史学习事件、原文、备份及冲突原件默认保留，用于学习回顾、查重和恢复。上传失败不会自动删除待传数据。

账号持有人可以管理或删除本人电脑、Google Drive 和备份中的资料。若希望彻底移除资料，应先停止同步，再分别检查本地、云端和备份副本；删除某一处的文件不代表其他副本已经删除。

可以在 Google 账户的第三方连接设置中撤销应用授权。撤销会阻止后续访问，但不会自动删除已有的本地或 Drive 学习记录。

公开网站与第三方服务

本网站是由 GitHub Pages 托管的静态说明页，不提供账户注册、登录、学习资料上传或表单提交。页面没有嵌入广告、分析脚本或主动设置跟踪 Cookie 的代码。

托管方可能为提供网站服务而处理网络请求相关信息；这类处理由 GitHub 的政策约束。本网站的静态页面不会接收归档程序的学习文件或 Google 凭据。

使用 Google Drive、ChatGPT 或其他来源服务时，这些服务另按各自规则处理在其服务中提交或保存的数据。请参阅相关服务的政策：

  • GitHub 隐私声明
  • Google 隐私政策
  • OpenAI 隐私政策

政策更新与联系

如应用的数据处理方式发生变化，本页面会更新，并标明更新日期。请勿通过联系邮件发送密码、验证码或 Google 授权凭据。
